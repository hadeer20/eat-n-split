# Eat-N-Split 💰

A React application that helps users split bills with friends and keep track of who owes whom.

## Features

- Add new friends with a name and image
- Select a friend to split a bill with
- Calculate your expense and your friend's expense
- Choose who paid the bill
- Automatically update each friend's balance
- Track who owes whom

## Technologies Used

- React
- JavaScript
- CSS
